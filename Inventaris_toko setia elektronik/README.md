# Inventaris Toko Setia Elektronik & Absensi Karyawan

Aplikasi manajemen inventaris toko dan sistem absensi karyawan berbasis web (React + Vite + Backend Node.js/TypeScript).

## Prasyarat
- Node.js (versi 16 atau lebih baru)
- npm

## Cara Menjalankan Aplikasi

### 1. Menjalankan Backend
Buka terminal baru, masuk ke direktori backend, install dependensi, dan jalankan server:
```bash
cd backend
npm install
npm run dev
```
*(Server backend akan berjalan di port default, misal `http://localhost:5000`)*

### 2. Menjalankan Frontend
Buka terminal terpisah, masuk ke direktori frontend, install dependensi, dan jalankan development server:
```bash
cd frontend
npm install
npm run dev
```
*(Buka URL yang tertera di terminal, biasanya `http://localhost:5173`)*
